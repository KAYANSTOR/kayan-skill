# كتالوج مهارات الذكاء الاصطناعي

فهرس مبسط لمهارات الوكيل ومجالات استخدامها:

- [`01-Core-Workflows/`](./01-Core-Workflows/): سير العمل الأساسي والمهام العامة التي يعتمد عليها الوكيل.
- [`02-Architecture-Quality/`](./02-Architecture-Quality/): الهندسة المعمارية، جودة الكود، الاختبارات، والأمان والأداء.
- [`03-UI-UX-Design/`](./03-UI-UX-Design/): مهارات تصميم واجهات المستخدم وتجربة المستخدم، بما فيها [`mobile-first-card-ui-architecture`](./03-UI-UX-Design/ui/mobile-first-card-ui-architecture/).
- [`04-Web-Frameworks/`](./04-Web-Frameworks/): أطر وأدوات تطوير الويب مثل React وNext.js.
- [`05-AI-Infrastructure/`](./05-AI-Infrastructure/): بوابات وموجهات الذكاء الاصطناعي مثل FreeLLMAPI وOmniRoute وAI Router.
- [`06-Code-Analysis/`](./06-Code-Analysis/): أدوات تحليل قواعد الكود وبناء الرسوم البيانية المعرفية مثل Graphify.
- [`07-SEO-Marketing/`](./07-SEO-Marketing/): مهارات تدقيق SEO وGEO والمحتوى والتقنيات التسويقية، بما فيها `claude-seo`.
- [`08-Security-Auditing/`](./08-Security-Auditing/): مهارات التدقيق الأمني، تحليل الثغرات، SAST، تصنيف المخاطر، وسلسلة توريد البرمجيات.

- [`DOCUMENTATION.md`](./DOCUMENTATION.md): دليل تفصيلي لدمج المهارات مع Claude Code وCursor وCodex وGemini CLI والوكلاء السحابيين، مع إرشادات Figma وAdobe وOpenCodeReview.

للاطلاع على قواعد العمل العامة للوكيل، راجع [`MASTER_AGENT_INSTRUCTIONS.md`](./MASTER_AGENT_INSTRUCTIONS.md).
